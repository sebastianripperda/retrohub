# Verhaltensregeln

RetroHub ist ein Hobbyprojekt für alle, die ihre Spielesammlung selbst betreiben möchten. Damit das hier für alle angenehm bleibt:

- **Freundlich und respektvoll** bleiben – gegenüber allen, unabhängig von Erfahrung, Herkunft, Geschlecht, Alter oder anderen persönlichen Merkmalen.
- **Sachlich** diskutieren, Kritik an Ideen und Code üben, nicht an Personen.
- **Geduldig** sein: Hier arbeiten Menschen in ihrer Freizeit.
- **Keine Belästigung**, keine Beleidigungen, keine Veröffentlichung privater Daten anderer.
- **Keine Raubkopien:** Keine Spieldateien, ROMs, BIOS-Dateien oder Links darauf.

Verstöße können zum Entfernen von Beiträgen und zum Ausschluss aus dem Projekt führen. Meldungen bitte vertraulich an die Betreuerin bzw. den Betreuer des Repositorys (über das GitHub-Profil) oder über „Report content“ bei GitHub.
